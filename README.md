# Rental-Management

> **Rental-Management** is a learning and research project. This project is developed by team of 2 members.  
> This project aims to explore and understand key concepts in practicing programming, data handling, and software design.

## Purpose

This project is developed as a **study and research initiative** by a small learning group. The main goals include:  
- Understanding and implementing a rental management system.  
- Practicing software development and database management skills.  
- Providing a reference for further study, experimentation, and research in related topics.

> ⚠️ **Note:** This project is intended solely for educational and research purposes and is **not for commercial use**.
